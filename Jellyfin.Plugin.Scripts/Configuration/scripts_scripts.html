Scripts

A script runs its steps when one of its triggers happens. Item kinds, users, and conditions narrow which events it runs for. Steps can message or control sessions, change items and users, call webhooks, queue server tasks, or run a command at any path the server can reach.

Secrets
Tokens and passwords this script uses. Use one as {{SECRET_NAME}} in a step, or $JF_SECRET_NAME in a command. Values are encrypted on the server, never shown again, left out of exports, and masked wherever they appear in the history.
Behavior
After a run, skip this script for the same trigger, user, and item until this many seconds pass. 0 turns it off.
A command receives each of these as an environment variable, such as $JF_ITEM_NAME, plus $JF_EVENT_JSON with all of them. In a step's text fields, use {{ITEM_NAME}}, {{ITEM_NAME:json}} inside a JSON string, or {{ITEM_NAME:url}} in a URL. Click one to copy it.
