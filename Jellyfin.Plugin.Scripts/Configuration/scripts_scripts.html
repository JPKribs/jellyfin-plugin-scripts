Scripts

A script runs its steps when one of its triggers happens. Item kinds, users, and conditions narrow which events it runs for. Steps can message or control sessions, change items and users, call webhooks, queue server tasks, or run a command at any path the server can reach.

Send a POST here with a Jellyfin API key from Dashboard, API Keys. The address picks the script and the key proves the caller may run it; a request with either one missing is refused. Schedule

                                    

                                        A script on a schedule runs as a Jellyfin scheduled task. Once you save, it is listed under
                                        Dashboard, Scheduled Tasks
                                        in the Scripts section, under this script's name and description. Set when
                                        it runs there, or run it by hand. It only runs on its schedule while the script is enabled.
                                    

                                    

                                

                            

                        


                        
                        

                            
Item kinds

                            

                                

                                    Run only for items of these kinds. Leave empty for every kind. Triggers without an
                                    item ignore this.
                                

                                

                                

                            

                        


                        

                            
Users

                            

                                

                                    Run only for these users. Leave all unchecked for everyone. On playback, any of the
                                    session's users counts. Triggers without a user ignore this.

Steps

                            

                                

                                    Run in order; drag or use the arrows to reorder. A failed step stops the rest unless it
                                    continues on error. Text fields accept {{NAME}} placeholders, listed under
                                    Variables. A step can have its own condition, and a command or HTTP request can save its
                                    output for the steps after it.

Secrets

                            

                                

                                    Tokens and passwords this script uses. Use one as {{SECRET_NAME}} in a step,
                                    or $JF_SECRET_NAME in a command. Values are encrypted on the server, never
                                    shown again, left out of exports, and masked wherever they appear in the history.
                                

                                

                                
                            

                        


                        
                        

                            
Behavior

                            

                                

                                    
                                    
                                    

                                        A schedule, a webhook, and Run now have no item or user of their own. Running for each
                                        gives the steps one: every library item of the script's item kinds, or every user, that
                                        passes its conditions. A trigger that already has one runs once as usual.
