Settings

Running
How many scripts may run at the same time. Further runs wait their turn.
A command step that sets no timeout of its own is stopped after this long.
The oldest runs are dropped past this many. 0 keeps none.
A Run command step runs a file at any path the server can reach. In Docker that is the path inside the container, so mount your scripts folder (for example -v /srv/jellyfin-scripts:/scripts:ro) and use /scripts/your-script.sh. The official image has a shell but no Python or most other interpreters, so a script should use /bin/sh or an interpreter you mount or install yourself.
Commands run on the server as the account Jellyfin runs under. Only add commands you trust.
