A Jellyfin plugin that runs your own scripts when something happens on the server, such as playback starting, an item being added, or a user signing in.

<br clear="left">

## Documentation

Installation and configuration are covered in the **[Scripts documentation](https://jpkribs.github.io/jellyfin-plugin-scripts/)**.

Plugin repository URL for Jellyfin:

```
https://raw.githubusercontent.com/JPKribs/jellyfin-plugin-scripts/master/manifest.json
```
